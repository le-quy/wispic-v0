# Wispic MVP Scope

## Goal

Build a stable first version that establishes the Wispic ecosystem without implementing every future feature.

## MVP Phase 1

### Public

- Homepage.
- Photography listing.
- Photography collection detail.
- Explore article listing/detail.
- Share article listing/detail.
- Services/About.
- Booking form.
- Wedding template listing.
- Wedding template preview.
- Public wedding invitation.

### User

- Authentication.
- Create wedding invitation.
- Select template.
- Enter wedding information.
- Upload photos.
- Preview.
- Save.
- Publish/unpublish.
- Manage own invitations.

### Admin

- Authentication/authorization.
- Photography CRUD.
- Photo management.
- Explore article CRUD.
- Share article CRUD.
- Wedding template CRUD.
- Booking management.
- Basic Wispic profile management.

## Phase 2 Candidates

- Search.
- Tags and advanced filtering.
- Related content.
- Style Explorer.
- Travel location pages.
- Photo tips.
- Analytics.
- Booking calendar availability.
- Email notifications.
- Social sharing.
- Advanced invitation customization.

## Future

- Multiple photographers.
- Photographer profiles.
- Customer reviews.
- Payment.
- Premium templates.
- Paid photography services.
- Customer portal.
- AI-assisted invitation generation.
- AI-assisted photography recommendations.

Do not implement Phase 2/Future functionality unless explicitly requested.
